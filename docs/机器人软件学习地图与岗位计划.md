## 1. 总览分层

```text
应用层：任务、导航、抓取、多机、AI
    ↑
中间件：ROS 2（话题/服务/动作/参数）、DDS、Launch、TF
    ↑
算法层：运动学、规划(MoveIt/Nav2)、滤波、视觉、控制
    ↑
驱动层：ros2_control、驱动节点、协议(CAN/串口/EtherCAT)
    ↑
嵌入式/板级：STM32 / ESP / Arduino、RTOS、外设
    ↑
底层：电机、传感器、电源、机械与安全
```

## 2. 必学主干（几乎所有机器人软件岗）

| 方向 | 学什么 | 本机对应 |
|------|--------|----------|
| **编程基础** | C++、Python、Linux、Git、CMake/colcon | 日常开发 |
| **ROS 2** | 节点、通信四件套、Launch、TF、URDF、QoS | 选型文档 + 鱼香书 |
| **坐标系与模型** | TF 树、URDF/Xacro、标定 | `rm_description`、相机外参 |
| **仿真与可视化** | RViz、Gazebo、日志调试 | `rm_65_gazebo`、Panda demo |
| **控制接口** | ros2_control、轨迹与状态 | MoveIt / 真机衔接 |
| **运动规划** | MoveIt 2 | 本地 MoveIt docs |
| **导航（底盘）** | Nav2 | 鱼香 chapt7/8 |
| **传感器** | 相机 / 激光 / IMU；同步与标定 | Orbbec SDK / ROS |

## 3. 嵌入式：学到什么程度

| 模块 | 应用集成岗 | 驱动/嵌入式岗 |
|------|------------|----------------|
| STM32 | 了解、能跟文档调通 | **主业** |
| ESP32 | 选学（WiFi/传感节点） | 常用外设方案 |
| Arduino | 原型即可 | 一般不作为量产主力 |
| RTOS | 概念 | **要会** |
| UART / CAN / EtherCAT | 会用、会抓日志 | **要会设计与排障** |
| Micro-ROS | 选学 | 选学 |

## 6. 按岗位选重点

| 方向 | 深挖 | 够用即可 |
|------|------|----------|
| **应用 / 系统集成** | ROS2、TF、MoveIt、相机、ros2_control 使用、联调 | STM32 细节 |
| **导航** | Nav2、定位建图、底盘 | MoveIt 深抓取 |
| **机械臂规划** | MoveIt、运动学、场景/抓取 | Nav2 很深 |
| **驱动 / 嵌入式** | STM32、电机、总线、实时 | MoveIt 插件开发 |
| **视觉 / 三维** | 相机 SDK、标定、点云、检测 | 底层伺服 |

你当前更接近：**应用 / 系统集成 + 机械臂 / 感知**。

## 7. 计划 A：应用集成岗 · 约 6 个月

假设每周有效学习 **8～12 小时**（可按实际伸缩）。

### 第 1–4 周：ROS2 与调试基本功

- [ ] 吃透话题 / 服务 / 动作 / 参数（读选型文档并自己写 2～3 个小节点）  
- [ ] TF：`view_frames`、静态/动态 TF、常见踩坑  
- [ ] Launch、参数 YAML、`ros2 topic/hz/echo/node`  
- [ ] 练习：fishbot / 书中基础章复现  

**验收：** 能独立解释任一 launch 里谁在发什么、TF 树是否完整。

### 第 5–8 周：模型 · 仿真 · ros2_control 概念

- [ ] URDF/Xacro 读写与改关节限位  
- [ ] RViz + Gazebo：睿尔曼 `rm_65_gazebo` / MoveIt demo  
- [ ] ros2_control：`JointTrajectory` 从哪来、状态怎么回  
- [ ] 读控制器 yaml（如 `ros2_controllers.yaml`）  

**验收：** 能画出「MoveIt → controller_manager → 硬件/仿真」数据流。

### 第 9–12 周：MoveIt 用熟

- [ ] Panda / `rm_65_config`：Plan、Execute、场景障碍  
- [ ] Setup Assistant 流程理解（可用现成 config，重在懂产物）  
- [ ] 写一个最小 C++ 或 Python 调 `move_group`（目标位姿 → 规划 → 执行）  
- [ ] 对照 [MoveIt 视频与书籍配套资源](./MoveIt_视频与书籍配套资源.md) 选一条跟完  

**验收：** 不打开 GUI 也能用代码让仿真臂到指定位姿。

### 第 13–16 周：感知与标定

- [ ] Orbbec：彩色/深度/点云、对齐、内参  
- [ ] 手眼标定概念与一次实操（眼在手外或眼在手上选一种）  
- [ ] 简单检测（色块 / YOLO 任一）→ 三维位置 → 与臂坐标系转换  

**验收：** 能把「图像上一点」变到「基座坐标系下的点」（误差可先粗糙）。

### 第 17–20 周：导航或抓取二选一加深

**选臂：**

- [ ] 避障场景、附着物体概念、简单拾放流程  
- [ ] 真机或仿真安全：速度缩放、限位  

**选底盘：**

- [ ] Nav2：建图、定位、导航到点  
- [ ] 代价地图与恢复行为直觉  

**验收：** 一条可演示的完整小 demo（「看到 → 算位姿 → 动」或「建图 → 导航」）。

### 第 21–24 周：工程化与作品集

- [ ] 整理一个自己的工作空间：README、launch、参数、已知问题  
- [ ] 日志、复现步骤、性能（hz、延迟）记录  
- [ ] （选）Docker / 开机自启  
- [ ] 简历项目：Orbbec + MoveIt 或 Nav2 + 鱼香车  

**验收：** 别人按 README 能在 30 分钟内跑起你的 demo。

## 8. 计划 B：嵌入式驱动岗 · 约 6 个月

### 第 1–4 周：单片机与外设

- [ ] STM32：GPIO、定时器、PWM、UART、中断  
- [ ] （选）Arduino / ESP32 做对比实验  
- [ ] 示波器 / 串口助手基本功  

### 第 5–8 周：电机与反馈

- [ ] 直流/步进/无服差异；编码器读数  
- [ ] PID 调速/位置（先单关节）  
- [ ] 安全：限流、限位开关  

### 第 9–12 周：总线与多节点

- [ ] CAN（强烈推荐）或 RS485  
- [ ] 简单协议设计（命令、状态、心跳）  
- [ ] FreeRTOS：任务、队列、优先级  

### 第 13–16 周：对接 ROS

- [ ] 串口/CAN → ROS 驱动节点（Python 可先，再 C++）  
- [ ] `joint_state` 发布与 `JointTrajectory` 订阅  
- [ ] 了解 ros2_control `hardware_interface` 插件思路  

### 第 17–20 周：实时与可靠性

- [ ] 周期抖动、丢包、看门狗  
- [ ] 急停与故障码  
- [ ] （选）Micro-ROS 或 EtherCAT 入门  

### 第 21–24 周：作品集

- [ ] 「一关节或小底盘：嵌入式 + ROS2 闭环」完整仓库  
- [ ] 文档：接线、协议、如何复现
