# ROS 2 通信选型：话题 / 服务 / 动作 / 参数

> 何时用话题发布订阅、何时用服务、何时用动作、何时用参数。  
> 按「数据性质 + 交互方式」选择即可。

---

## 1. 一句话对照

| 机制 | 适合什么 | 不像什么 |
|------|----------|----------|
| **话题 Topic** | 持续、单向、可多对多的数据流 | 不保证「对方一定处理完再回你」 |
| **服务 Service** | 一问一答、马上要结果、时间短 | 不适合跑很久、中途要进度 |
| **动作 Action** | 要跑一段时间、要进度、可取消 | 不要做成「发完就忘」的无限流 |
| **参数 Parameter** | 配置、阈值、模式开关（偏静态/缓变） | 不要拿来传高频传感器数据 |

---

## 2. 话题（发布 / 订阅）

### 什么时候用

- 传感器、图像、点云、`JointState`、里程计、TF（本质也是持续广播）
- 「有就发、谁爱听谁听」，发布者不关心订阅者个数
- 需要较高频率、允许多节点同时听

### 特征

- 异步、流式
- 默认可丢失（取决于 QoS）；不是「调用一次必有一次回执」

### 例子

- 相机发布 `/camera/color/image_raw`
- 手臂发布 `/joint_states`
- MoveIt / RViz 显示规划轨迹相关话题

### 别用话题当

- 「帮我算一下 IK，把结果给我」这种请求-响应 → 用服务或动作
- 「把最大速度改成 0.3」这种配置 → 用参数

---

## 3. 服务（Service）

### 什么时候用

- 短请求、短应答：查信息、开关、设一次状态
- 需要明确成功 / 失败返回值
- 调用方愿意**等一会儿**，但通常是秒级以内

### 特征

- 同步感强：`call` → 等待 → `response`
- 没有官方「进度条」；执行太久会像卡住

### 例子

- Orbbec：`get_device_info`、`set_streams_enable`、读写标定
- 「重新加载地图」「保存一帧」「设某个开关」

### 别用服务当

- 规划一条复杂路径并执行几分钟 → 用动作
- 每秒几十次的深度图传输 → 用话题

---

## 4. 动作（Action）

### 什么时候用

- 目标导向、耗时长：运动规划 + 执行、导航到点、抓取流程
- 需要：**目标 → 持续反馈 (feedback) → 最终结果 (result)**，且常要**可取消**

### 特征

- 底层仍基于话题，但语义是「带目标的长任务」
- 比服务适合长时间；比纯话题更有「这次任务」的边界

### 例子

- MoveIt：`move_group` 的规划 / 执行相关 action
- Nav2：导航到某个 pose
- 「执行这条轨迹，并报告完成百分比」

### 别用动作当

- 只查一下序列号 → 服务就够
- 纯传感器广播 → 话题

---

## 5. 参数（Parameter）

### 什么时候用

- 节点配置：分辨率、帧率、命名空间、是否开深度、速度上限
- launch / yaml 里写好，启动时加载；或运行中偶尔改（动态参数）
- 「这个节点怎么工作」而不是「这一帧数据是什么」

### 特征

- 键值配置，不是数据总线
- 可落在参数服务器；改配置 ≠ 发一帧图像

### 例子

- `camera_name`、`enable_depth`、`velocity_scaling`
- MoveIt / 控制器 yaml 中的大量配置

### 别用参数当

- 传点云、图像、高频关节角 → 话题
- 「现在去抓杯子」这种任务 → 动作

---

## 6. 决策流程图（实用版）

```text
是配置 / 阈值 / 开关吗？
  └─ 是 → 参数

是持续数据流、多节点要听吗？
  └─ 是 → 话题

是「做一件事，要结果」吗？
  ├─ 很快做完，只要最终答案 → 服务
  └─ 较久，要进度 / 可取消 → 动作
```

## 8. 常见误用

1. **用话题模拟服务**：发「请求话题」、另开「结果话题」——能做，但不如服务 / 动作清晰。  
2. **用服务传图像**：大带宽 + 阻塞，易卡死。  
3. **用参数当遥控指令**：改参数触发逻辑可以，但高频指令仍应用话题 / 动作。  
4. **长任务塞进服务**：客户端超时、无法友好取消。

## 9. 速查表

| 你想做的事 | 选 |
|------------|----|
| 连续发传感器数据 | 话题 |
| 多人同时听同一数据 | 话题 |
| 查一下设备状态 / 开关某功能 | 服务 |
| 改节点默认行为（分辨率、限速） | 参数 |
| 规划并执行一段运动、要进度可取消 | 动作 |
| 导航到目标点 | 动作 |
| 广播 TF / joint_states | 话题 |
