# 点云是做什么的？比深度 / 普通识别强在哪

对应 SDK 示例：`./bin/ob_point_cloud`  
配套 Qt 可视化程序：`qt_pointcloud_viewer/`（见该目录 README）

---

## `ob_point_cloud` 在做什么

把深度图（可选叠彩色）转成 **三维点云**：每个点有 XYZ（毫米），彩色点云还有 RGB，并可保存为 `.ply`（如 `RGBPoints.ply`）。

---

## 点云主要用途

面向的是 **三维空间里的几何**，不是“图上画个框”：

- 测真实距离、尺寸、体积
- 抓取 / 避障：目标在相机坐标系下的 3D 位姿
- 建图、配准、重建（SLAM、多视角拼接）
- 工业检测：平面度、缺口、高度差
- 用 PCL / Open3D / 自研 OpenGL 做滤波、分割、拟合平面等

对 Gemini 335L：点云来自深度传感器的 3D 结构；彩色只是给点上色，方便观察。

---

## 和「普通识别」「深度」的对比

| | 普通 2D 识别（如 YOLO） | 深度图 | 点云 |
|--|--|--|--|
| 输出 | 图上的框 / 类别 | 每个像素的距离（2.5D） | 每个点的 XYZ（真 3D） |
| 知道什么 | “大概在画面哪里” | “这块有多远” | “在空间里具体在哪、形状如何” |
| 缺什么 | 没有可靠真实尺度和姿态 | 仍是栅格图，任意 3D 运算不方便 | 计算更重，点更“散”，常需滤波 |

### 比普通 2D 识别强在

1. **有真实尺度**：框只有像素位置；点云能量“离相机 0.8 m、宽 12 cm”。
2. **有几何**：轮廓、平面、高度、是否可抓，不单靠纹理。
3. **对光照/纹理相对更稳**：纯白墙、暗处，深度/点云往往仍可用。
4. **更贴合机器人**：路径规划、抓取位姿用的是 3D。

### 比“只用深度图”强在

- 深度图是图像坐标；点云已按内参投影到相机坐标系 XYZ。
- 平面分割、ICP、碰撞检测、和机械臂坐标对齐时更自然。
- 深度图擅长“看远近”；点云擅长“在空间里算几何”。

---

## 一句话

- **普通识别**：认“是什么、在图上哪”。
- **深度**：认“有多远”。
- **点云**：认“在三维空间里长什么样、在哪”——给测量、抓取、建图、3D 感知用。

实际系统常见组合：**2D 检出目标 → 用深度/点云算 3D 位置和姿态**。
